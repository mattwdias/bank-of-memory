## Fala Sugerida (Roteiro Melhorado)

A inspiração veio de como a nossa própria memória funciona. Quando a gente dorme, o cérebro revisita o dia, reforça o que se repetiu e descarta o resto. O Devin web até ganhou uma feature parecida, chamada *Dreaming*, mas no CLI isso não existia. Então eu trouxe esse conceito para o terminal com a skill `memory-bank`.
