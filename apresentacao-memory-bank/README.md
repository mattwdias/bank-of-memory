# Apresentação: Ensinar uma vez só (`memory-bank` no Devin CLI)

Esta pasta contém **1 subpasta para cada slide** da apresentação (numeração `01` a `19`, mantendo o salto original de `07` para `10`).

Dentro de cada pasta `slide-XX/`, você encontra:
- **`slide-XX.md`**: o texto completo do slide, a **fala melhorada** e a imagem já vinculada no Markdown.
- **`slide-XX.png`**: a foto correspondente àquele slide (e `slide-XX-alt.png` nos slides em que foram enviadas duas fotos do mesmo slide).
