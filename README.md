# bank-of-memory

O *dream* do Devin CLI: consolida os resumos de sessão num memory bank curto e confiável.

| Arquivo | O que é |
|---|---|
| `SKILL.md` | a skill |
| `bank-of-memory.pptx` | a apresentação |

## Instalar a skill

```bash
mkdir -p ~/.claude/skills/bank-of-memory
curl -L -o ~/.claude/skills/bank-of-memory/SKILL.md \
  https://github.com/mattwdias/bank-of-memory/raw/main/SKILL.md
```

No Windows, a pasta é `%USERPROFILE%\.claude\skills\bank-of-memory\`.
